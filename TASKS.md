# TASKS: Локальный голосовой ассистент для Codex CLI

## Подход к задачам

Задачи разделены вертикально: каждый блок должен давать проверяемый пользовательский результат, а не просто отдельный технический слой. Например, вместо отдельной большой задачи "сделать STT" блок должен доводить поток до состояния "пользователь сказал фразу и увидел распознанный текст".

Каждый блок выполняется последовательно. Следующий блок начинается только после того, как предыдущий можно запустить и проверить локально.

## Правила выполнения

- Работать в текущей директории проекта.
- Не создавать отдельные Git worktree или дополнительные копии проекта без явной просьбы.
- STT и TTS должны работать локально, без внешних API.
- Ответы ассистента не логировать постоянно по умолчанию.
- Временные файлы допустимы, если они перезаписываются и нужны для связи между процессами.
- Debug-логи можно добавлять только как явный режим, выключенный по умолчанию.
- После каждого блока обновлять этот документ: отмечать выполненные пункты и добавлять найденные проблемы.
